В этом проекте я классифицировал пассажиров Титаника по тому, выжили они или нет. На тренировочных данных я использовал корреляционную матрицу и классификатор деревьев для поиска признаков, бесполезных для обучения. Далее масштабировал данные и искал лучшую из трёх моделей (Logistic Regression, Random Forest, Gradient Boosting) — сначала через кросс-валидацию, а затем через GridSearchCV, чтобы ещё и подобрать параметры. В итоге я выбрал Gradient Boosting с параметрами, на которых GridSearchCV показал лучший результат — но при проверке на реальном Kaggle-тесте оказалось, что дефолтные параметры Gradient Boosting работают лучше, чем подобранные через GridSearchCV. Это показало, что подбор параметров может немного переобучаться под конкретную кросс-валидационную выборку, а не всегда обобщается на новые данные.

Также в этом проекте я ещё раз усвоил урок, что тестовые данные всегда нужно трансформировать (encoder/scaler) на основе параметров, полученных на тренировочных данных, а не пересчитывать заново — иначе получится расхождение между train и test и заметное падение качества на новых данных.
